## 怎么用

1. 点上表里的 **Open in Colab**
2. 打开后先点 **文件 → 在云端硬盘中保存一份副本（File → Save a copy in Drive）**，在自己的副本里做题，进度才会保存
3. 从「0 · 准备」开始依次运行：0.1 安装 TransformerLens，0.2 加载模型

每个人都运行在自己的 Colab 环境里，互不影响。CPU 就能跑完全部题目。
